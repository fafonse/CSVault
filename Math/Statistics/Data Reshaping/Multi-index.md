A type of column that can fit multiple variables into it.


| ID  | Variable | Value |
| --- | -------- | ----- |
| 1   | height   | 180   |
| 1   | weight   | 220   |
| 2   | height   | 172   |
| 2   | weight   | 140   |
| 3   | height   | 150   |
> The *Variable* column is a *multi-index* in this case.
