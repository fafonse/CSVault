The process of evaluating the [[Nielson Heuristics|heuristic]] adherance of a design.

**Overview**:
1. Go through UI several times
2. Use violations to redesign / fix problems
3. Each evaluator produces a list of problems


## Phases
1. Pre-evaluation training
	- Give context + domain knowledge needed
2. Evaluation
	- Use 3-5 evaluators at most
	- Use varying skill levels of evaluators (novice/expert)
3. [[Risk Classification and Factors|Severity Rating]]
	- Give each violation a *priority*
	- Do as an individual, then as a group
	- Frequency + Impact + Persistence
4. Debrief
	- Discuss outcome, team priorities, possible fixes, etc.
