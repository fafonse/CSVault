Categories of different principles of [[User Experience|UX design]].

1. Users should always be informed of the programs current status
2. System should use real-world terms, not computer terms
3. Give users an "out"
	- *Cancel, undo, redo, back, etc.*
4. Across UX be consistent and follow standards
5. Filter inputs instead of creating errors when possible
6. Make possible actions visible instead of forcing users to memorize their options
	- TUI vs. GUI
7. Allow experienced users to be faster while keeping novices in mind
	- `Ctrl+C` vs. Right-click
8. Keep it minimal and *aesthetic*
9. Help users deal with errors when they occur
10. Add help pages + documentation
