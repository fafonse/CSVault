Like a *think aloud*, but done by you (usability expert).

- Ideally not the same people who designed/built the system
- Move through the prototype like a user
- Set up tasks real users might do
- Can be cheap/fast (no recruiting necessary)

> This is great, but actual [[Ethnography|users]] make better test subjects. You still might run into [[Expert Blindness]].


## How to do it

1. Set up a sequence of tasks
2. For each task, ask 4 questions
	1. Does effect of the current cation match the user's goal?
	2. Is the action visible?
	3. Will the user recognize the action as the correct one?
	4. Will the user understand the feedback? (sounds, visuals, etc.)

> [!example] Photo Copier
> First step is to "push power on" (obvi!!!)
> But why shouldn't a user assume that the machine is already on? Why does it need to ever be "off"?
> And also, how do you know if it is powered on? Is there an indicator light?
