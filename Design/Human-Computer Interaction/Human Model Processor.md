A cognitive modeling method used to calculate how long it takes to perform a task.

- Allows designers to test systems without users, similar to [[Heuristic Evaluation|heuristic evaluation]]
- Does not account for everything in the real world, which tends to not follow laws

## Subsystems

Three subsystems: *Perceptual*, *Motor*, and *Cognitive*.

Each system has it's own attributes:
- *Decay Time*
	- How long is memory kept in the system?
- *Processing Cycle Time*
	- How fast is stuff processed?
- *Storage Amount*
	- How much memory can that system have?

### Perceptual
The system of us percieving *stimuli*

- Discrete and limited
- Two stimuli in the same cycle tend to blur together
	- Animation appears smooth after ~10fps

Stats:
- Cycle time = 100ms
