A type of array.
It's very efficient to check if an element is in the array.

- No duplicate entries
- Unordered

```python
# Using {} to initialize
beatles = {'Paul', 'George', 'Ringo', 'John'}`

# This is very efficient
baboolean = 'Paul' in beatles # true
baboolean = 'Fabrizio' in beatles # false
```
